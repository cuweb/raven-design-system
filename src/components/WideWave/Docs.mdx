# Wide Wave

A page-level content container with a black or red background and a decorative wave graphic along its top edge. Always renders a `<section>` with `data-color-scheme="dark"`, inverting text and headings to white. Nests inside `Main` and wraps layout components like `Column`, `Article`, and `Aside`. Three max-width presets align with the WordPress block editor's alignment system.

## When to use

Use `WideWave` for a high-impact accent band — a hero closer, a call-to-action strip, or a divider between content sections — where the decorative wave graphic reinforces brand identity. Add `contentWidth` when you want the wave band to span one width while keeping children in a narrower readable column.

## Import

```tsx
import { WideWave } from '@cuweb/raven-design-system';
```

## Basic usage

```tsx
// Default — content width, black background
<Main>
  <WideWave>
    <Column cols="3">...</Column>
  </WideWave>
</Main>

// Red background
<Main>
  <WideWave color="red">
    <Column cols="2">...</Column>
  </WideWave>
</Main>

// Full-bleed
<Main>
  <WideWave maxWidth="alignfull">
    <Column cols="3">...</Column>
  </WideWave>
</Main>

// Full-bleed with content constrained to 1024px
<Main>
  <WideWave maxWidth="alignfull" contentWidth="aligncontent">
    <Column cols="2">...</Column>
  </WideWave>
</Main>

// Full-bleed with content constrained to 1280px
<Main>
  <WideWave maxWidth="alignfull" contentWidth="alignwide">
    <Column cols="2">...</Column>
  </WideWave>
</Main>
```

## Max-width presets

| `maxWidth`       | Token                        | Description                                          |
| ---------------- | ---------------------------- | ---------------------------------------------------- |
| `"aligncontent"` | `--rds--layout-content-size` | Standard readable content width                      |
| `"alignwide"`    | `--rds--layout-wide-size`    | Wider — for card grids and media-rich sections       |
| `"alignfull"`    | `--rds--layout-full-size`    | Default — full viewport width, hero and accent bands |

These names and tokens mirror the WordPress block editor's alignment system so that React templates and WordPress block themes share the same layout vocabulary.

## The `color` prop

| Value     | Background                     | Wave graphic                   |
| --------- | ------------------------------ | ------------------------------ |
| `"black"` | `--rds--color-black` (default) | `cu-waves-hard-edge-black.svg` |
| `"red"`   | `--rds--color-primary-dark`    | `cu-waves-hard-edge-red.svg`   |

## The `contentWidth` prop

When set, `contentWidth` wraps all children in an inner div constrained within the outer layout:

| Value            | Inner content width                                             |
| ---------------- | --------------------------------------------------------------- |
| `"aligncontent"` | 1024px — standard readable content width                        |
| `"alignwide"`    | 1280px — wider, for card grids and media-rich layouts (default) |
| `"alignfull"`    | Full viewport width                                             |

Omitting `contentWidth` keeps the existing behaviour: children are direct children of the root and the root's `is-layout-constrained` applies.

## CSS classes

| Class                   | When applied                                           |
| ----------------------- | ------------------------------------------------------ |
| `cu-widewave`           | Always                                                 |
| `cu-widewave--black`    | `color="black"` (default)                              |
| `cu-widewave--red`      | `color="red"`                                          |
| `cu-widewave__wave`     | Always — decorative wave graphic element               |
| `has-global-padding`    | Always — horizontal gutter from `--rds--layout-gutter` |
| `aligncontent`          | `maxWidth="aligncontent"`                              |
| `alignwide`             | `maxWidth="alignwide"`                                 |
| `alignfull`             | `maxWidth="alignfull"` (default)                       |
| `is-layout-constrained` | Always — constrains children to content / wide widths  |

## Design tokens

| Token                        | Used for                                 |
| ---------------------------- | ---------------------------------------- |
| `--rds--color-black`         | Background colour when `color="black"`   |
| `--rds--color-primary-dark`  | Background colour when `color="red"`     |
| `--rds--spacing-large`       | Internal padding, wave graphic offset    |
| `--rds--spacing-x-large`     | Bottom padding at `md`+                  |
| `--rds--radius-md`           | Border radius on non-full-width sections |
| `--rds--layout-content-size` | `aligncontent` max-width                 |
| `--rds--layout-wide-size`    | `alignwide` max-width                    |
| `--rds--layout-full-size`    | `alignfull` max-width (100%)             |

## Accessibility

- `WideWave` always renders a `<section>` element. Add `aria-label` or `aria-labelledby` when the section's purpose should be surfaced to screen reader landmark navigation.
- Without an accessible name, `<section>` is not exposed as a landmark, which is acceptable for generic layout sections.
- `data-color-scheme="dark"` is applied automatically so text and headings inside invert to white — do not manually override text color on children.
- The decorative wave graphic (`cu-widewave__wave`) has no accessible meaning and carries no text alternative, which is appropriate since it is purely ornamental.
