## Refactoring a Component

Prompt 1:

```
I am rebuilding components and I want to follow the instructions for components, stories and styles that are in the .github/instructions folder. I am focusing on loader components listed in /docs/refactor.md at line 184, we will do these one at a time.

Let's start with the Block Loader, I have provided the legacy component for reference for the refactor.
```

Note: Include old component as a file / folder
