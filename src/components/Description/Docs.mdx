# Description

A container for labelled metadata and native disclosure items — programme details, event attributes, contact information — in stacked, columnar, or collapsible layouts.

## When to use

- Displaying labelled facts about a programme, event, or person (e.g. "Programme", "Faculty", "Duration")
- Pairing terms with longer prose or mixed content (paragraphs, lists) using the accordion variant
- Presenting metadata in a scannable two-column layout at wider viewports with `useColumns`
- Any context where a semantic term/definition structure is more appropriate than a plain table

## Import

```tsx
import { Description } from '@cuweb/raven-design-system';
```

## Basic usage

Stacked layout — each term sits above its definition:

```tsx
<Description>
    <Description.Meta term="Programme">Bachelor of Computer Science</Description.Meta>
    <Description.Meta term="Faculty">Faculty of Engineering and Design</Description.Meta>
    <Description.Meta term="Duration">4 years (120 credits)</Description.Meta>
</Description>
```

Two-column layout — term is pinned to a 260 px left column at `md` and wider:

```tsx
<Description>
    <Description.Meta term="Programme" useColumns>
        Bachelor of Computer Science
    </Description.Meta>
    <Description.Meta term="Faculty" useColumns>
        Faculty of Engineering and Design
    </Description.Meta>
</Description>
```

Collapsible accordion items:

```tsx
<Description>
    <Description.Accordion term="Admission requirements">
        <p>Applicants must hold an Ontario Secondary School Diploma...</p>
    </Description.Accordion>
    <Description.Accordion term="Career outcomes">
        <p>Graduates work in software engineering, data science, and research.</p>
    </Description.Accordion>
</Description>
```

`Description.Meta` renders a semantic description list for each term/definition pair. `Description.Accordion` renders an independent native disclosure item. It accepts `term` and `children`; `hasBorder` is not a supported prop, and the standard item dividers are always applied.

## CSS classes

| Class                             | Condition                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| `cu-description`                  | Always — applied to the root `<div>`                                                       |
| `cu-description__item`            | Always — applied to each `Description.Meta` `<dl>` and `Description.Accordion` `<details>` |
| `cu-description__item--columns`   | When `useColumns` is `true` on `Description.Meta`                                          |
| `cu-description__item--accordion` | Always on `Description.Accordion` items                                                    |
| `cu-description__term`            | Always — applied to the `<dt>` in `Description.Meta` and `<summary>` in Accordion          |
| `cu-description__content`         | Always — applied to the `<dd>` in `Description.Meta` and content `<div>` in Accordion      |
| `cu-description__trigger`         | Always on the `<summary>` inside `Description.Accordion`                                   |
| `cu-description__accordion-icon`  | Always on the chevron icon inside the accordion summary                                    |

## Accessibility

- `Description.Meta` renders each term/definition pair as its own `<dl>` with `<dt>` and `<dd>` elements; the outer `Description` is a neutral `<div>` so it can also contain native disclosures.
- `Description.Accordion` uses `<details>` and `<summary>`, providing built-in disclosure semantics and keyboard activation with Enter or Space. Items start closed and remain independent; they are not grouped with a `name` attribute.
- The visible term labels the summary, and the chevron is decorative (`aria-hidden` by `<Icon>`). Its rotation follows the native `open` state.
- The summary retains a visible focus outline for keyboard navigation. Standard dividers do not convey open/closed state by themselves; the disclosure and rotated chevron do.
