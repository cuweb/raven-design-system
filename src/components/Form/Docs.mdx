# Form

An accessible form wrapper and field primitives that integrate with React Hook Form.

## When to use

- Build forms that use React Hook Form for state and submission.
- Compose native input, textarea, select, radio, or checkbox controls with RDS styling.
- Display field-scoped validation feedback from React Hook Form or an application resolver.

## Import

```tsx
import { Form } from '@cuweb/raven-design-system/Form';
```

Install `react-hook-form` in the consuming application. Validation remains application-owned; use React Hook Form rules or a resolver such as Zod's `zodResolver`.

## Basic usage

```tsx
import { useForm } from 'react-hook-form';
import { Form } from '@cuweb/raven-design-system/Form';

interface ContactValues {
    name: string;
    email: string;
}

function ContactForm() {
    const methods = useForm<ContactValues>({
        defaultValues: { name: '', email: '' },
    });

    return (
        <Form
            methods={methods}
            onSubmit={async (values) => {
                await saveContact(values);
            }}
        >
            <Form.Group cols={2}>
                <Form.Field
                    name="name"
                    label="Name"
                    required
                    rules={{ required: 'Name is required' }}
                />
                <Form.Field
                    name="email"
                    label="Email"
                    type="email"
                    required
                    rules={{
                        required: 'Email is required',
                        pattern: {
                            value: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
                            message: 'Enter a valid email address',
                        },
                    }}
                />
            </Form.Group>
            <button type="submit" disabled={methods.formState.isSubmitting}>
                Submit
            </button>
        </Form>
    );
}
```

For schema validation, configure a resolver in `useForm`; install that schema library and resolver in the application, not RDS. Use `useWatch` in a small child component for conditional fields so only that section subscribes to the watched value.

| ------------------------------------------------------------------------------- | -------------------------------------------- |

## Accessibility

- Uses a semantic `<form>` and labeled native form controls; radio and checkbox groups use `<fieldset>` and `<legend>`.
- Connects helper/error text with `aria-describedby`, reports invalid fields with `aria-invalid`, and exposes validation feedback with `role="alert"`.
- Required state is conveyed by a visible asterisk and `aria-required`; actual required validation must be configured through React Hook Form rules or a resolver.
- Error state is not conveyed by color alone: a text message is rendered for the invalid field.
